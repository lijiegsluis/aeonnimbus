The record

Each row is a call published with entry, stop, target and size before it played out. Open a row to see the slip.

Cumulative contribution

Each closed call's return multiplied by its published size, added in exit order. A simple sum with no compounding and no overlap adjustment.

Benchmark not shown. The S&P 500 overlay needs a price-history file (see the audit for the one-file fix). Until then this chart makes no relative-performance claim.

All calls

Return is price return on the published entry. Blended calls average the lots. A 100% hit rate on a small sample says little about the future; the worst closed call is shown in the table as it was.
